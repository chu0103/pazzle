PUZZLE ARCADE · 预览


  

    
合集里的七款游戏

    
    
      
  • 方块拼图：棋盘从小到大（4×4 → 8×8），把托盘里的方块拖进去铺满
    • 
      
  • 逻辑拼图：固定 8×8；开局已放好 3 块黑色拼图（占 3 / 2 / 1 格），
          把剩下 8 块拖进去填满
    • 
      
  • 照片拼图：一张照片切成 N×N（3×3 → 8×8），碎片打乱后拖回原位；
          每块都要回到它原来的格子才算过关（摆满但摆错不算）。
          关卡页顶部有「难度」快捷条可直接选 3×3~8×8；棋盘默认铺一层很淡的原图当参照，
          5 秒后自动收起（轻触棋盘可随时切换显示/隐藏）
    • 
      
  • 图片找不同：上下两张几乎一样的图，点出 B 图里每一处改动（3 → 8 处）。
          难点在"点错也算数"——错点会扣星；卡住可用「提示」圈出一处
    • 
      
  • 瓶子颜色推理：看隐藏目标、交换相邻两瓶，把颜色排成正确顺序
    • 
      
  • 密码推理：拼一行颜色提交，按逐格反馈（绿=位置对 / 白=颜色对位置错 /
          黑=没这个色）推理出隐藏密码；后段换成「只报各状态个数」的经典 Mastermind 玩法
    • 
      
  • 移车出库：6×6 停车场里车辆只能沿自身轴向滑动，把白色警车滑到右侧出口。
          点首页卡片先选难度（入门 / 进阶 / 困难 / 专家，各 5 关），
          拖不动某辆车时会抖动并描红"是谁挡住了它"
    • 
    

  


  

    
操作

    
    
      
  • 拼图三款：把托盘里的碎片拖进棋盘，自动吸附网格；
          照片拼图要求每块回原位，摆满但摆错不算过
    • 
      
  • 棋盘上的碎片也能再拖起来重摆（逻辑拼图的黑色固定块不行）
    • 
      
  • 图片找不同：点按上下任一图上的差异位置即可标记
          （点错会画红叉并扣星，3 星 = 全程没错点）；卡住按「提示」圈出一处
    • 
      
  • 瓶子 / 密码推理：点按选择，按「提交 / 提交猜测」看反馈
    • 
      
  • 移车出库：按住车沿轴向拖动，松手吸附到最近合法格；
          拖动时车下方会画出「能滑到哪」的轨道；拖不动时会抖动 + 描红挡路的车
    • 
      
  • 底部按钮：拼图是撤销 / 重置 / 提示，找不同是提示 / 重来
    • 
    

  


  

    
这套预览和小游戏是同一份代码

    
    
      
  • 逻辑层：js/game/（两款游戏的生成器）+ js/scenes/（共用玩法场景）
    • 
      
  • 宿主层：js/platform/browser.js ↔ wx.js
    • 
      
  • 小游戏里换成 wx 适配层即可，玩法代码一行不改
