PUZZLE ARCADE · 预览


  

    
合集里的两款游戏

    
    
      
  • 方块拼图：棋盘从小到大（4×4 → 8×8），把托盘里的方块拖进去铺满
    • 
      
  • 逻辑拼图：固定 8×8；开局已放好 3 块黑色拼图（占 3 / 2 / 1 格），
          把剩下 8 块拖进去填满
    • 
    

  


  

    
操作

    
    
      
  • 把托盘里的方块拖进棋盘
    • 
      
  • 方块自动吸附网格，填满全部格子即过关
    • 
      
  • 棋盘上的方块也能再拖起来重摆（黑色固定块不行）
    • 
      
  • 底部有撤销 / 重置 / 提示
    • 
    

  


  

    
这套预览和小游戏是同一份代码

    
    
      
  • 逻辑层：js/game/（两款游戏的生成器）+ js/scenes/（共用玩法场景）
    • 
      
  • 宿主层：js/platform/browser.js ↔ wx.js
    • 
      
  • 小游戏里换成 wx 适配层即可，玩法代码一行不改
    •
