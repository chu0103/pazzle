照片拼图 / 图片找不同那几页含真实图片：直接双击用 file:// 打开时，画过图片的画布会被判为跨源污染而无法导出， 因此本页在 file:// 下会自动禁用图片加载（这两款显示色块兜底，方块/逻辑快照照常正常）。 要看含真实图片的快照，请用本地 HTTP 打开：在项目根目录执行 python -m http.server 8080 然后访问 http://localhost:8080/test/visual.html。 单张细看用 ?only=NN&w=390（NN 见每张下方的编号）。
